আইএসপি বিল কালেক্টর (Bill Collector) - cPanel হোস্টিং গাইড
============================================================

১. আপনার cPanel একাউন্টে লগইন করুন।
২. File Manager এ যান এবং public_html এর ভেতর একটি নতুন ফোল্ডার তৈরি করুন (যেমন: api)।
৩. এই ফোল্ডারের (api) মধ্যে নিচের ফাইলগুলো আপলোড বা পেস্ট করুন:
   - api.php
   - customers.json
   - packages.json
   - payments.json

৪. api ফোল্ডারের পারমিশন ৭৫৫ (755) বা ৭৭৭ (777) নিশ্চিত করুন যাতে অ্যাপ ডাটা রাইট করতে পারে।
৫. অ্যাপের সেটিংস (Settings) পেজে গিয়ে আপনার Server URL সেট করুন:
   উদাহরণ: https://yourdomain.com/api/

অ্যাপ থেকে 'সার্ভার সিঙ্ক' চাপলেই এটি আপনার হোস্টিং এর সাথে সরাসরি কানেক্ট হয়ে ডাটা সিঙ্ক করবে!
